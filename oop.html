Experiment 1 — A simple class
class Student:
    def __init__(self, name, score):
        self.name = name
        self.score = score

    def introduce(self):
        print(f"I am {self.name}. My score is {self.score}.")

student1 = Student("Anu", 85)
student2 = Student("Bala", 92)

student1.introduce()
print(student2.score)
print(student1 == student2)

Experiment 2 — Inheritance and overriding
class Animal:
    def speak(self):
        print("An animal makes a sound.")

class Dog(Animal):
    def speak(self):
        print("Woof!")

class Cat(Animal):
    def speak(self):
        print("Meow!")

animals = [Dog(), Cat(), Animal()]

for animal in animals:
    animal.speak()
Explore with your AI Tutor
  • Which classes inherit from Animal?
  • Why does the same method call produce different behaviour?
  • What is method overriding?
  • Python does not support traditional signature-based method overloading in the same way as Java. Explore default arguments, variable arguments and other Python approaches.

Experiment 3 — Protecting valid data
class BankAccount:
    def __init__(self, balance=0):
        self._balance = balance

    @property
    def balance(self):
        return self._balance

    def deposit(self, amount):
        if amount <= 0:
            raise ValueError("Amount must be positive.")
        self._balance += amount

account = BankAccount(100)
account.deposit(50)
print(account.balance)
Explore with your AI Tutor
  • Why use _balance instead of a public attribute?
  • Does a single underscore make an attribute truly private in Python?
  • How could a property validate changes to the balance?
  • Explore abc.ABC and abc.abstractmethod.

Experiment 4 — Custom addition
class Vector:
    def __init__(self, x, y):
        self.x = x
        self.y = y

    def __add__(self, other):
        return Vector(
            self.x + other.x,
            self.y + other.y
        )

    def __str__(self):
        return f"({self.x}, {self.y})"

v1 = Vector(2, 3)
v2 = Vector(4, 5)

print(v1 + v2)
Explore with your AI Tutor
  • How does Python interpret v1 + v2?
  • Why does __add__ return a new Vector?
  • What should happen when someone adds a Vector to an incompatible object?
  • Explore the with statement and context managers.

Experiment 5 — Composition
class Engine:
    def start(self):
        print("Engine started.")

class Car:
    def __init__(self):
        self.engine = Engine()

    def start(self):
        self.engine.start()
        print("Car is ready.")

my_car = Car()
my_car.start()
Explore with your AI Tutor
