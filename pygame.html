2Open a game window

First, understand how to initialize Pygame, create a display window, process quit events, and close the program cleanly.

First experiment: a minimal game window 
import pygame

pygame.init()

screen = pygame.display.set_mode((640, 400))
pygame.display.set_caption("My First Pygame Window")

clock = pygame.time.Clock()
running = True

while running:
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            running = False

    screen.fill((235, 245, 255))
    pygame.display.flip()
    clock.tick(60)

pygame.quit()

Save this as main.py and run it using the Python interpreter selected in VS Code.

Explore with your AI tutor
  • Why do we call pygame.init()?
  • Why does the program need a loop?
  • What happens if we remove the event-processing code?
  • What do screen.fill() and pygame.display.flip() do?
  • What is the purpose of clock.tick(60)?

3Learn the building blocks

Work through these concepts using small experiments rather than memorizing a long list of functions.

A. Draw shapes, colours and text

Learn RGB colour values, rectangles, circles, screen coordinates, fonts, and text rendering.

Challenge: Draw a simple scene containing a sun, a house, and a tree. Change the colours and positions.

B. Respond to keyboard and mouse input

Learn the event queue, key presses, mouse clicks, and the difference between an event and a continuously held key.

Challenge: Change a circle's colour when the user clicks it.

C. Animate and move objects

Learn coordinates, velocity, frame rate, and how game state changes over time.

Challenge: Move a ball across the screen and make it bounce at the edges.

D. Detect collisions and keep score

Explore rectangles, collision detection, random positions, game rules, and score updates.

Challenge: Make a player catch a falling object and increase the score.

E. Add images, sound and game states

Explore loading images and sounds, start screens, game-over screens, and restarting a game.

Challenge: Add a sound when an object is caught and a message when the game ends.
